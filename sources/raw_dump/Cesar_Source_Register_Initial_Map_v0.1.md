# Cesar Source Register \'97 Initial Map\
\
## Executive summary\
\
The five PDFs form a **coordinated price-list and technical-planning library**, not a set of marketing catalogs.\
\
For the UCON / Cesar pilot, the practical hierarchy appears to be:\
\
1. **Kitchen System** \'97 primary module and dimensional source for preliminary kitchen layouts.\
2. **Project Guidelines** \'97 global rules, finishes, collections, commercial framework, and cross-system definitions.\
3. **Linear Elements** \'97 countertops, worktops, panels, splashbacks, shelves, and related dimensional constraints.\
4. **Home Elements** \'97 living systems, shelving, wall systems, workstations, and furniture outside the primary kitchen cabinet schedule.\
5. **Bathroom Collection** \'97 separate bathroom planning system; useful only when the pilot scope includes vanities or bathroom cabinetry.\
\
The main limitation is document age: the covers indicate a **2021 price list with later update notation**. Technical structure may remain useful, but current production availability, prices, lead times, finishes, and commercial terms require confirmation from Cesar / DzineElements.\

# Initial source-set risks\
\
1. **Version validity**\
   - The documents are labeled as 2021 price lists with update notation.\
   - Current production validity is not established.\
\
2. **Pricing usability**\
   - List values alone are insufficient for client or dealership pricing.\
   - Dealer coefficient, discount, freight, duty/tariff, tax, receiving, damage responsibility, and installation scope are not confirmed.\
\
3. **Cross-book dependency**\
   - A cabinet code may depend on a finish, collection, handle system, plinth, top, or customization rule located in another book.\
\
4. **Collection contamination**\
   - Dimensions or options from one collection cannot be assumed valid for another.\
\
5. **Nominal versus production dimensions**\
   - Preliminary dimensions may not represent final manufacturing, installation, clearance, or appliance requirements.\
\
6. **Special-element approval**\
   - Custom dimensions and modifications may require separate factory feasibility and quotation.\
\
7. **Information density**\
   - The combined source set exceeds 1,500 pages. Extracting everything would create a complex and difficult-to-maintain system before the pilot scope is defined.\
