# Pilot Extraction Scope \'97 Bobby / First Southern California Kitchen\
\
## Executive summary\
\
The pilot should **not** attempt to digitize the Cesar catalog.\
\
The correct scope is to extract only the geometry and planning rules required to:\
\
1. recreate Bobby\'92s room accurately;\
2. place preliminary Cesar cabinet modules in SketchUp;\
3. test appliance integration, clearances, fillers, corners, and elevations;\
4. generate a structured package for Elda / DzineElements to review and quote.\
\
The first pilot output is **not an order** and must not imply confirmed availability, pricing, finish feasibility, or production compatibility.\
\
The real constraint is not SketchUp modeling. It is determining which Cesar modules are actually applicable to Bobby\'92s selected collection, opening system, appliance package, and US-market requirements.\
\

# Pilot completion standard\
\
The first extraction phase is complete when:\
\
- Bobby\'92s layout can be modeled with standard-size preliminary blocks;\
- every block has a source or explicit assumption;\
- appliance and door collisions can be reviewed;\
- fillers and end conditions are visible;\
- no unsupported module is presented as confirmed;\
- Elda can review the layout without first interpreting the entire Cesar catalog;\
- the output can be converted into a preliminary quote-request package.\
\
It is **not** complete merely because the kitchen looks correct in SketchUp.\
\
