## Extraction Limitations

| Limitation | Effect on preliminary planning | Required control |
|---|---|---|
| The source repeatedly requires feasibility checking for modified elements/items. | A listed modification code or point reference does not by itself confirm production approval for a specific cabinet. | Submit the exact unit, dimensions, front, finish, internal equipment and appliance condition to Cesar / DzineElements. |
| Many modification rows provide a surcharge code but no permissible dimensional interval. | SketchUp can represent a placeholder reduced/increased cabinet, but not a production-valid size grid. | Treat unspecified minimums, maximums and increments as “Not found in source.” |
