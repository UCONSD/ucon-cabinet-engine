## Extraction Limitations

| Limitation | Impact on preliminary planning | Required treatment |
|---|---|---|
| The source is a technical price list, but several product pages use diagrams and condensed tables that do not fully define installation cavities, connector types, or field wiring sequence. | SketchUp geometry can show approximate envelopes, but not production cutouts or electrical rough-in. | Use placeholders and retain source-page references. |
| Some tables show lamp dimensions in centimeters while the extraction standard is millimeters. | Conversion has been limited to direct decimal-to-millimeter conversion where clear. | Verify every selected item during technical review. |
| Bali wattage values are not clearly visible in the extracted table text. | Load calculation cannot be completed from this extraction. | Needs detailed extraction or written confirmation. |
| Vivara uses one repeated code label across sizes in the visible table. | Code-to-size uniqueness is unclear. | Needs Elda confirmation before component coding. |
| The transformer page states both “maximum capacity 45W” and shows 48W versions in the table. | There is a direct load-rating ambiguity. | Do not size or specify transformers until written clarification. |
| Luminous glass shelf power-adapter kit is marked “Not available version 110V.” | U.S. compatibility is unresolved despite other lighting-system pages showing USA transformer versions. | Do not use for U.S. production planning until written confirmation. |
| Standard power distributor code is not clearly visible in the extracted source text. | BOM and control-system coding are incomplete. | Needs detailed extraction or written confirmation. |
| Cable lengths, connector families, junction locations, wall-switch interfaces, and field electrician scope are incomplete for most products. | Electrical coordination cannot be treated as production-ready. | Use only schematic routing and issue an electrical coordination RFI. |
| No U.S. listing, certification, branch-circuit requirement, driver location rule, or code-compliance statement was found in the extracted lighting section. | U.S. electrical approval cannot be inferred. | Subject to U.S. electrical review and written manufacturer confirmation. |
| Compart and Trilli pages contain many module-specific lighting surcharges and codes beyond the first examples summarized here. | This file is not a complete module-by-module price-list transcription. | Perform detailed extraction only after pilot layout identifies relevant module families. |
