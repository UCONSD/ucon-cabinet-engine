## Extraction Limitations

| Limitation | Impact on v0.1 | Required control |
|---|---|---|
| The Tall Units section contains many item-level variants across printed pages 90-173. | This v0.1 captures the source-defined families and planning-relevant configurations, but does not normalize every individual code into a separate row. | Complete item-by-item extraction only after the preliminary SketchUp family list is accepted. |
| Overview pages show visual matrices with width/depth combinations that are not always reliably attributable to a named unit from text extraction alone. | Some family-level width ranges remain broad or marked unclear. | Verify each candidate against its detailed printed page before creating a production component. |
| Maxima, Intarsio and Tangram appear in section headers, while detailed pages often show Maxima / Intarsio. | Collection applicability cannot be generalized across every row without item-by-item review. | Confirm collection applicability by code with Elda before using the component library commercially. |
| Appliance labels identify intended appliance type, not tested model compatibility. | No Miele or other appliance model is confirmed by this extract. | Obtain appliance-specific compatibility and cutout confirmation from Cesar / DzineElements. |
| Pricing columns and groups are visible, but commercial conditions, currency, freight, tariff, tax and dealer margin are outside this extraction. | No final pricing can be created from this table. | Keep pricing fields informational only until commercial terms are confirmed. |
| Pullout systems such as Tandem and Convoy rely on mechanism details and accessory pages. | Internal geometry is not safe for SketchUp component production at this stage. | Use envelope-only placeholders or defer until mechanism schedule is extracted. |
| The source references surcharges for side-panel depth, feet, wall-hung versions, Servo Drive, Servo Flex and LEGRABOX. | These are not included as complete bill-of-material rules in v0.1. | Extract surcharge/accessory dependencies separately if quote preparation requires them. |
| H.78 and H.84 alignment families are distinct. | Combining them would create incorrect front-line and appliance-zone geometry. | Maintain separate family tags/components for H.78 and H.84. |
| Top elements are explicitly marked “without fixings.” | A top element row is not a complete installation package. | Keep fixing method as an unresolved technical dependency. |
