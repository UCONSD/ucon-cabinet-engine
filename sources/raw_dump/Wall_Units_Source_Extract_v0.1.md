## Extraction Limitations

| Limitation | Source-based effect | Control applied |
|---|---|---|
| The source is a 2021 price list with a later update notation, not confirmation of current 2026 production availability | A visible code or size cannot be treated as currently orderable | All availability remains subject to Cesar / DzineElements confirmation |
| Wall-unit overview diagrams show multiple configurations in compact visual rows | Text extraction can separate dimensions but does not always preserve the exact icon-to-width relationship | Only clearly mapped detailed rows are marked `confirmed from source`; ambiguous groupings are flagged |
| Detailed pages contain many item-level codes and finish-price columns | This v0.1 table is not a complete SKU transcription | Code families and clearly visible examples are retained; remaining items require detailed extraction |
| Pricing columns 1-11 are visible, but current commercial meaning and dealer coefficients are not established | Price groups cannot be converted into client pricing | Pricing group field records only the visible group structure |
| Hood units identify Cesar Virgola or Virgola No Drop configurations | They do not establish compatibility with Miele, Wolf, Best, Faber, or another independent hood | Hood rows are reference-only until hood technical data and current availability are confirmed |
| Dish-drainer units state that width cannot be reduced | Custom-width assumptions are not permitted | Dish-drainer placeholders must use listed widths only |
| Compound units reach 1500, 1800, and 2400 mm | These may represent divided/compound fronts rather than a universal single carcass/front | They are not P1 generic component-library candidates |
| D570 wall units occur only at selected heights/configurations | D570 cannot be treated as a universal deep wall cabinet | Separate reference component only |
| Some detailed rows show D620 references near wall-unit schedules | Classification and intended application are not sufficiently clear in this extraction | Marked for Elda confirmation; no SketchUp component created |
| Corner rows use corner geometry such as 1000 × 400 or 750 × 750 | These values cannot be entered as ordinary linear cabinet widths | Corner components require dedicated geometry |
| Open units are indexed in a separate catalog section | They are outside the requested Wall Units schedule scope | Excluded from v0.1 |
| Internal shelf counts are not consistently readable from the overview | Generic shelf counts would be invented | Use external dimensions only in first SketchUp placeholders |
| Handles are expressly noted as not included in the price | Handle presence cannot be assumed from cabinet price rows | Handles remain separate planning metadata |
| Technical page notes closing-strip requirements adjacent to tall units or walls for certain hinged wall units | Cabinet envelope alone does not establish usable door clearance | Model a clearance/filler condition when applicable; exact application requires design review |
