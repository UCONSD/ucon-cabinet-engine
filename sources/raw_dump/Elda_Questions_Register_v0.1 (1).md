# Elda Questions Register v0.1

## Use Instructions

Use this register as the working confirmation tracker with Elda / DzineElements before converting the Cesar v0.1 planning library into final SketchUp components, quote-request packages, pricing, production orders, or installation instructions. Record written answers, dates, ownership, and follow-up status in the same row. Source-derived questions are retained from the workbook `Elda Questions` sheets; broader workflow questions are included only where supported by `Current_Source_System_Status_v0.3`.

## Production-status warning

> **PRELIMINARY PLANNING ONLY.** Unresolved questions cannot be treated as confirmed design, pricing, ordering, production, or installation information. Catalog presence, historic item codes, source points, price groups, and preliminary SketchUp placeholders do not authorize a client commitment or production release.
