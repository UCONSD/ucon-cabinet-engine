# Разведка H.84 — что ещё не извлечено (2026-09-28)

Запрос Андрея: для высоты 84 извлечь «всё остальное» — tall, панели посудомойки,
base fillers и прочее. Это разведка, ничего не извлечено. Страницы — печатные
(PDF = печатная + 2), книга — `CESAR - 2 Kitchen System.pdf`. Числа кодов —
по текстовому слою, до сверки с картинкой.

## Сначала развилка — какой высоты периметр

Карточка 7612, 2026-09-25, **решено**: остров — Tangram H.84 на цоколе 6;
**периметр — Maxima 2.2 H.78 на цоколе 10**, чтобы у посудомойки Thermador
DWHD660EPR был цоколь 100 (ей нужно 92–190 мм, Vol. 10.1 стр. 223).

Колонны (холодильник, винная, духовка, кофемашина) и посудомойка — на
периметре. Значит, при действующем решении им нужны **tall «for base unit
H.78»** и дверь посудомойки H.78, а не H.84. Если периметр переходит на H.84,
цоколь 6 снова упирается в посудомойку. До извлечения — решение Андрея.

## Что есть в registry для H.84 сейчас

- База H.84: стр. 49 и 51 (61 код). Мойки H.84: стр. 53–54, прямые (18 кодов).
- Tangram H.84 (6) и сайдборд H.138 (1). Стенные H.84 и сушки H.84.
- Торцевые панели Maxima 45° высотой 840 — **уже есть** (end_panels_maxima).

**Находка стр. 415 (USA elements for base units H.84):** «Base unit for countertop
hob», jumbo-ящики, ширины в дюймах — **BL9150 / BM9150 = 91,4 см (36″)**, плюс
76,2 / 106,7 / 121,9. Это тумба под варочную панель 36″ американской ширины.
Для CIT36YWBB это кандидат рядом с BM0967 (ширина 914 вместо 900, то есть
вырез 883–886 внутри корпуса с запасом). С downdraft — те же вопросы про длину
ящика, что в Q34.3. Там же: основание под духовку BL/BM6197, 7697 (61 / 76,2),
BL/BM7699 с ящиком, двери под USA-холодильник BL7657 / BL9657.

### B. Посудомойка и приборы — стр. 55–56 (Base units H.84 for household appliances)

- Высокая дверь посудомойки VL0640 (60) / VL0740 (75, с нержавеющим шкафом
  GBBF01 15 см); VL8659 (Shaker). Дверь с платформой VL0630 / VL0730 (78/75).
- Ниша под холодильник VL0601 / VN0601; дверь стиральной машины VL0650.
- Профиль-заполнитель между посудомойкой и столешницей 995945 (45) / 995946 (60).
- Проверить при извлечении: дверь Cesar 60 см против ниши 24″ (610) у
  DWHD660EPR.

   под приборы Thermador.
