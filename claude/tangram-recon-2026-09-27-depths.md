# Tangram: какой глубины модули M (Maxima) рядом с Tangram — разведка 2026-09-27

Вопрос Андрея: «модуль M represents Maxima, и, подозреваю, глубина у него разная — 62 и, возможно, 57».

## Что напечатано
| пример | где | модули Tangram | модули M (Maxima) |
|---|---|---|---|
| остров 315 | PG печатная стр. 116 (и изометрия на стр. 108) | 2× A, 2× D, 2× E | **6× Maxima 2.2 base units D. 57** |
| у стены 309 | PG печатная стр. 116 | 2× C | **3× Maxima 2.2 base units D. 62** |
| полуостров 304,5 | PG печатная стр. 117 | 2× C, E, B, 2× P | **4× Maxima 2.2 base units D. 67** |
| буфет H.138 | PG печатная стр. 117 | 2× A H.138 | **3× Maxima H.138 D. 35** (витрины) |
| остров C M C, 124 | брошюра PDF стр. 5 | C, C | глубина M не подписана (124 = 62 + 62) |

Итог: **у модулей M четыре глубины — 35, 57, 62, 67**, и какая нужна, решает модуль Tangram рядом. A стыкуется с 35, E (концом 57) — с 57, C — с 62.

## D.57 — не каталожная глубина базы
- Таблица глубин Kitchen System (печатные стр. 20–23) даёт базы только 35 / 47 / 62 / 67. **Базы 57 нет.** В Kitchen System D.57 встречается только у навесных (печатные стр. 207–210).
- Kitchen System печатная стр. 548 (PDF 550), «Shaping and special reductions»: уменьшение глубины баз, **код 989350, 92 пункта**. Предел для тумб 62 с ящиками — 9 см, для тумб 35 с ящиками — 2 см, для 67 с ящиками — 4 см; невозможно на тумбах с внутренними аксессуарами.
- **Толкование:** Maxima D.57 в примере острова — это D.62, уменьшенная на 5 см (989350). Это часть 3 вопроса Q29 к Элде.

## Для движка и для 7612
- Предупреждение на стыке BL0601 (d.62) + E (конец 57) — верное: по книге там должна стоять Maxima D.57.
- **Решение Андрея 2026-09-27: заказную глубину (989350) НЕ делать.** Толкование «D.57 = D.62, уменьшенная на 5 см» остаётся вопросом к Элде (Q29, часть 3), в движок не идёт.
- Уменьшение глубины (989350) в движке заведено только как код в `_manifest.json` → `modifications`; у тумб его пока нельзя заказать. Ширина и высота уже заказываются (`with_ordered_width`, `with_ordered_height`). **Кандидат в следующую задачу:** заказная глубина для тумб, чтобы D.62 можно было сделать D.57 с кодом 989350.
- На скруглённом конце острова 315 модуль D повёрнут на 90°: его сторона 62 идёт поперёк острова, под ним A (35). Отсюда глубина конца 64,5 + 37,5 = 102 = 62 + 35 + 2 × 2,5.

## Решение Андрея 2026-09-27: остров отправляется Элде как есть
В `Tangram_test` собраны два острова:
- **остров 315** из Project Guidelines (печатная стр. 116), ряды Maxima d.57 — тестовые, в заметках объектов «TEST ONLY»;
- **остров C–MMMM–C** с южным рядом E–B–B–E, ряды d.62 (брошюра, PDF стр. 6).

Конфликт C (62) + E (57) на концах южного ряда (уступ 50 мм) **не исправляется**. Андрей собирает остров как есть и отправляет Элде. Она строит его в Metron по-своему, мы сравниваем её SKP и заказ с нашей моделью. Это тот же круг, что в `decisions-2026-09-03-factory-assigned-codes.md`: код и решение её, геометрию проверяем мы. Сравнение закроет Q29 (стыки и D.57) и Q30 (кривые).
